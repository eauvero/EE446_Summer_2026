This contains all the Jupyter Notebooks used to create and train the models for this project. 

* Before running these notebooks, all the pre-processed training data was compressed into a file called `eye_gaze_train_lsr.zip`. This file was uploaded onto a Google Drive folder called `KaggleGazeCapture`.

* Source for pre-trained weights is https://github.com/NavodPeiris/MobileNet_96x96_greyscale_weights/blob/main/mobilenetV2_0.05_96x96_greyscale_weights.h5
